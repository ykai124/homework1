## 解題說明

本題要求撰寫一個遞迴函式來計算集合 $S$ 的 Power Set（冪集）。Power Set 是由集合 $S$ 的所有可能子集合所組成的集合。

### 解題策略

## 解題策略

1. **遞迴處理元素：**從集合的第一個元素開始，依序處理每一個元素。

2. **分成兩種情況：**對目前的元素分成「不加入子集合」和「加入子集合」兩種情況，分別進行遞迴。

3. **遞迴終止條件：**當所有元素都處理完後，表示目前的子集合已經完成，將其輸出。

4. **產生完整 Power Set：**透過每個元素的兩種選擇，產生所有可能的子集合，最後得到完整的 Power Set。


## 程式實作

以下為主要程式碼：
#include <iostream>

using namespace std;

void PowerSet(char set[], char subset[], int n, int index, int size)
{
    if (index == n)
    {
        cout << "{";

        for (int i = 0; i < size; i++)
        {
            cout << subset[i];

            if (i < size - 1)
            {
                cout << ",";
            }
        }

        cout << "}" << endl;

        return;
    }

    // 不選目前的元素
    PowerSet(set, subset, n, index + 1, size);

    // 選目前的元素
    subset[size] = set[index];
    PowerSet(set, subset, n, index + 1, size + 1);
}

int main()
{
    char set[] = {'a', 'b', 'c'};
    char subset[10];

    int n = 3;

    PowerSet(set, subset, n, 0, 0);

    return 0;
}

1. **時間複雜度：**程式的時間複雜度為 $O(n2^n)$。

2. **空間複雜度：**程式的空間複雜度為 $O(n)$。
